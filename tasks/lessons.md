# tasks/lessons.md — corrections captured so they aren't repeated

- **Bill PDF is not machine-extractable here.** The uploaded "translated" PDF was
  generated by WeasyPrint with subsetted CID fonts (Identity encoding), so text
  extraction yields glyph codes, not characters. Rely on the user's transcription
  or a re-shared image for figures.

- **Transcribed bill figures don't reconcile** under PGVCL telescopic slabs:
  - Energy ₹4,902.50 ≠ 743 units at Other-Areas slabs (₹3,163 ×2-scaled / ₹3,514 single);
    ₹4,902.50 implies ~1,010 units on single slabs.
  - Reading diff: 34007−32246 = 1,761, but bill says "1,917" and "Consumption 743".
  - Fuel ₹4,179 ÷ 743 = ₹5.62/unit — implausibly high FPPPA.
  → Treat billed **units**, **FPPPA**, **duty basis** as UNCONFIRMED. Golden test
    stays pending until the user confirms. Everything stays config-driven.

- **What IS reconciled / trustworthy:** Other-Areas slab rates (₹3.05/3.50/4.15/5.20),
  fixed-charge tiers (₹15/25/45/70 per month by load), Fixed Charge ₹30 = ₹15/mo × 2
  → sanctioned load ≤2 kW. Tariff effective 2022-04-01. Total Company Charge ₹10,153.11
  = Fixed+Energy+Fuel+Duty (internally consistent).

- **LAN-locality is real.** The P110 local API only answers on the plug's LAN.
  M0/M1 cannot be live-verified from the cloud build env (no plug here). Build the
  poller with mocked/unit tests; user verifies on the always-on LAN device.

- **Unit normalization on ingest:** get_current_power → W; today/month_energy → Wh;
  runtime → minutes; some firmware reports embedded current_power in mW (guard:
  divide by 1000 if implausibly large). Canonical DB units: Wh / W / minutes.
